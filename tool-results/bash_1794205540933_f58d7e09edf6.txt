PRIORITY P1 · Main cause of rejection · Confirmed on 8 live pages

Problem
Mortgage, Loan, BMI, Income Tax, Due Date, Concrete, Conception and Ideal Weight all use the same

PART F — RESUBMISSION

Fix 16. When and how to resubmit
Resubmit about 3–4 weeks after the last fix is live, and only when every box below is ticked.
Google publishes no official waiting period, so this is a practical rule: it gives crawlers time to re-read
the changed pages and lets you add fresh content in the meantime. Request review once. A rejected
request costs you time.

Pre-resubmission checklist
☐ All worked examples recomputed; old numbers searched out of the repo and blog (Fix 7)

☐ No page describes a feature the tool lacks; “Click Calculate” removed (Fix 9)
☐ Income tax uses current IRS tables and states the tax year (Fix 10)
☐ Terminology fixed: nominal APR, fertile window, fraction steps, password entropy (Fix 11)
☐ Test script runs in CI with a reference case per indexed calculator (Fix 12)
☐ “People also search for” removed everywhere (Fix 2)
